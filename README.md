# hxyfront-62012 纺织染整小样台

离线可用的纺织染整实验室小样管理前端：批次台账、染料配方、温度曲线、Lab 色差评审，数据全部保存在本机浏览器（localStorage），刷新不丢失，无需后端。

## 功能

- **批次台账**：内置 5 个演示批次，支持新增、编辑、移除。
- **完整记录字段**：面料成分（多种纤维占比）、克重、染料配方（owf%）、浴比、温度曲线、实际/下限保温时间与温度、后整理方式与完成时间、标样 Lab。
- **按客户订单筛选**：订单号 / 批次号 / 客户名关键字 + 成分 + 状态组合筛选，列表与统计实时联动。
- **Lab 色差对比**：CIE76 ΔE 自动计算、标样/实测色块对照（Lab→sRGB 换算）。
- **工艺曲线摘要**：自动生成「升温 X℃/min → 保温 → 降温」文字摘要与 SVG 曲线图。
- **回评与历史**：每次回评记录实测 Lab、ΔE、客户确认、评审人、备注及当时配方快照。
- **状态自动判定**：
  1. 实际保温 **未达配方下限**，或后整理 **未满 24 小时** → 只能「待检」（仍可先录入实测）；
  2. 条件齐备后，**ΔE ≤ 1.0 且客户确认** → 「评审通过」；
  3. 已实测但未满足上述条件 → 保留实测数据并标「待复染」。
- **改方失效机制**：修改染料清单/用量、浴比或保温下限即配方升版，旧版本回评标记为「已失效」但历史与快照保留，不参与状态判定；列表、色差对比、曲线摘要、筛选结果全部同步更新。

## 技术栈

React 19 + Vite 7 + TypeScript（零运行时第三方依赖，纯本地运行）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62012。生产构建 `npm run build`，`dist/` 为纯静态产物，可断网直接部署/打开。
