# 纺织染整小样台（离线）

面向纺织染整实验室的离线小样管理前端：记录面料成分、克重、染料配方、浴比、温度曲线、保温时间、后整理、Lab 色差与评审结果，支持按客户订单筛选。

## 功能

- **批次管理**：内置 4 条演示批次，支持新增、编辑、移除（批次号唯一校验）。
- **工艺记录**：面料成分、克重、染料名称与用量（% o.w.f）、浴比、保温下限、温度曲线节点（时间→温度，内置棉/涤纶/锦纶三套预设）、实测保温、后整理方式与完成时间。
- **Lab 色差**：标样/实测 Lab、ΔE*ab（CIE76）、Lab→sRGB 色块直观看色。
- **评审规则（自动判定）**：
  - 实测保温未达配方下限，或后整理完成未满 24h → **待检**，不能录入回评；
  - 达标后方可回评：ΔE ≤ 1.0 **且** 客户确认 → **通过**；
  - 否则保留实测数据并标记 **待复染**。
- **配方版本**：修改染料/用量/浴比/保温下限会生成新版本，旧回评立即失效（置灰标注）但完整保留历史；列表状态、Lab 对比、曲线摘要、筛选结果同步联动。
- **筛选**：客户订单（含客户名/数量）、面料成分、评审状态、关键字。
- **离线可用**：无任何外部网络依赖；数据存 `localStorage`（刷新/重开保留），生产构建注册 Service Worker 缓存应用外壳，断网仍可打开。

## 技术栈

React 19 + Vite + TypeScript，纯前端、无后端。

## 运行

```bash
npm install
npm run dev        # 开发，端口 62012
npm run build      # 生产构建（产物在 dist/，可直接静态托管）
npm run preview    # 本地预览生产构建
npm run check:rules  # 运行评审状态机的规则测试（25 条）
```
